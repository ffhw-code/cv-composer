## 一、项目优化目标（终点）

| 标准 | 内容 | 验收下限 |
|---|---|---|
| 标准 1 | 基础编辑稳定、流畅、可扩展；画布准确、灵敏直观；网页文档流自动排版 | **二档必须达标** |
| 标准 2 | AI 解析简历图片，接近 1:1 复刻到画布 | **必须达标一档**：关键字段 ≥90%、版式结构一致度 ≥80% |
| 标准 3 | AI 助手会使用编辑器全部编辑操作 | **二档必须达标**，并**尽量**达标一档 |
| 标准 4 | AI 助手是简历专家，能给出建议与优化 | **只做一轮**主观评估，报告须标注「主观数据」 |

## 二、项目现状（起点）

`cv-composer`：聊天式 AI 简历编辑器（React 19 + TypeScript + Vite 8 + Zustand 5 + TipTap 3 + Tailwind 4 + dnd-kit）。**纯前端，无后端**；AI 请求由浏览器直连模型服务商；部署 GitHub Pages。

- **形态**：纯前端、无后端；AI 请求由浏览器直连服务商；API Key 只存在浏览器当次会话。
- **能力边界**：简历图片复刻目前只有单步流程；PDF / Word 直接报错；AI 链路存在「同轮重复工具调用、打满轮次却记为成功」等可靠性问题（即阶段 1 要治的对象）。
- **验收状态**：**四项交付标准均未验收**；验收测量（阶段 2）被阶段 1 与额度前置卡住。
- **工程侧**：四项全绿（2026-09-17 实测）；用例数动态基线 **324**（2026-09-17）；体积 / 耗时等指标的原始值与判定见 `docs/quality/02`。HEAD 属易变事实，以 `git log` 实时为准，本文件不记录。
