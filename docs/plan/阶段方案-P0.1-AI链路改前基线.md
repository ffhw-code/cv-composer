> **状态**：`已计划`（未开工）。**本方案不声称改变指标** —— 它是 `P0.2` 改动的改前基准（`AGENTS.md` 第 7 节基线门控）。**不估算工时**（该指标已作废）。

## 一、为什么做

`P0.2` 要改「同轮重复工具调用、打满轮次记为成功、静默假成功、额度类 403 归因」与工具 schema。这些改动**声称改变**工具调用次数、单轮 tokens 与调用成功率 —— 没有改前数据，改后就没有对照，任何「优化了 X%」都是编的。本小阶段只做一件事：在**未改动的代码**上把这几项采一次。

## 二、测什么（只测本任务要改的）

| # | 指标 | 用途 |
|---|---|---|
| 1 | 单轮工具调用次数（均值 / 最大） | 对照改后守卫效果；历史证据：`add_module` 单轮最高 14 次 |
| 2 | 单轮 token 消耗（`totalTokens` 均值 / 最大） | 对照改后；历史样本：`generate-resume` 单轮最高 51.5k |
| 3 | 工具调用成功率与参数解析分布（`ok` / `repaired` / `invalid`） | 排除「参数解析变差被误读成优化」 |
| 4 | **打满 `MAX_TOOL_ROUNDS`（`=8`，`src/components/AI/useAiChat.ts:44`）的轮次占比**，及这些轮次的 `turn.outcome` 分布 | 核心证据面：证明「打满却记为 `success`」确实存在 |
| 5 | `redundant` 计数（`errorKind:'redundant'`） | 当前只有 `set_style`/`set_content` 对刚创建 id 的窄守卫会记（`useAiChat.ts:343`），用于对照改后的通用守卫计数 |

## 三、怎么采（可执行）

- **命令**：`npm run ai-baseline`（harness：`baseline/aiBaseline.run.ts`）。
- **档位**：`deepseek-flash`（官方端点 `https://api.deepseek.com`）。**采集期间不得更换档位。**
- **场景与样本量**：`AI_BASELINE_SCENARIOS=add_module,generate-resume`、`AI_BASELINE_ITERATIONS=3` → 共 **6 轮**，背靠背连续跑。
- **场景集固定**：`add_module,generate-resume` 两个（本方案 5 项指标都能被它们覆盖）。`tool-error-retry` 的场景重设计归 `P0.2` 第 8 项（0 token），**不纳入本基线**。
- **守卫三件套**：`AI_BASELINE_SCENARIOS` / `AI_BASELINE_ITERATIONS` / `AI_BASELINE_MAX_TURN_TOKENS`（默认 30k）；`AI_BASELINE_OUT_DIR` 用**绝对路径**。
- **Key**：只经环境变量 `AI_BASELINE_KEY` 传入，**绝不写入任何文件**（含报告、日志、命令行）。
- **环境**：本机、同一机器；同场跑一次 bench 取环境哨兵比 `r`（`computeLayout` 12 模块与 `findModuleById` 的较小者）。
- **建议预算上限**：**40 万 tokens**（依据：同档位历史约 5.4 万 tokens/轮 × 6 轮 ≈ 32 万，加约 25% 余量）。**实际上限以老板当场确认的为准**；单轮显著超出该量级 → 立即停手报老板，**不得自行加预算**。

## 四、开工前置（缺一不可）

1. 老板确认**本次预算上限**与 **DeepSeek 官方渠道余额**；
2. `P0.2` 的**第 5 项（harness 与浏览器共用 `tool_choice` 开关）已完成**（0 token 部分 + 1 场景 × 1 轮冒烟）—— 官方端点下 harness 若仍写死 `tool_choice:'auto'`（`baseline/aiBaseline.run.ts:503`）会直接 400，采不到数据。这是 `P0` 内部唯一的前后交叉；
3. 冒烟确认非上传轮次真实请求返回 200，且不出现 `Thinking mode does not support this tool_choice`。

## 五、验收条件

1. 6 轮全部完成，或如实标注 `abort` / 不完整（**不得**把残缺数据当基线）；
2. 明确给出判定：**改前是否存在「打满 8 轮且 `turn.outcome = success`」**；
3. 数据落 `metrics/`（`AI_BASELINE_OUT_DIR`），并在 `docs/testing/测试报告.md` 落结论，标 commit、档位、命令、样本量、哨兵比 `r`；
4. 报告不出现 Key；
5. 标 `suspect` / 有效轮数为 0 的数据如实保留并显著标注，**不得**当基线引用。

## 六、允许改动 / 禁止

- **允许**：`baseline/**`（仅为跑通采集所必需）、`docs/testing/测试报告.md`、`docs/quality/**`（数据）。
- **禁止**：改 `src/**`（改前基线必须建立在未改动的产品代码上）；换档位；把 Key 写进文件。
